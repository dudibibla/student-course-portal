## General Functionality
This is an E-Commerce website built with Spring Boot MVC. It allows users to browse products, add items to a shopping cart using sessions, and complete purchases. It includes user registration and authentication via Spring Security, and an Admin dashboard to manage products.

## Compile and Run Instructions
To compile and run the project, please execute the following commands:
```bash
mvnw clean package
mvnw spring-boot:run
```
